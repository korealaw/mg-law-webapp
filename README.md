# MG 새마을금고법 톡톡

새마을금고 간부자격 학습을 위한 **무료·비상업적·비공식 참고 학습도구**입니다.

## v8.4 학습 구조

1. 누구나 무료 기본학습 50문항
2. 누구나 무료 미니 모의고사 50문항
3. **무료 100문항을 모두 완료한 뒤** 추가 문제가 필요한 이용자에게만 생성형 AI 연구 설문을 선택적으로 안내
4. 실제 설문 제출이 자동 확인되면 별도 `/extra/` 페이지에서 추가 100문항 자동 개방
5. 추가100은 같은 브라우저에서만 이용 가능하며 URL만 전달해서는 열리지 않음

설문은 **새마을금고 임·직원과 관련한 생성형 AI 연구·조사**를 위한 것이며, 무료100 이용의 조건이 아닙니다. 추가문제가 필요하지 않다면 설문에 참여하지 않아도 됩니다.

## 기존 설문 참여자

일부 문항과 예시 표현이 소폭 보완·변경되었습니다. 기존 응답은 그대로 연구자료로 활용하며 이전 참여자가 다시 참여해도 괜찮습니다. 재참여는 자유입니다. 다만 v8.4의 추가100 자동개방은 현재 설문 제출을 확인하는 방식이므로 추가문제를 원하는 기존 참여자는 무료100 완료 후 현재 설문을 다시 제출해야 합니다.

## 문제자료 성격

이 문제와 해설은 주요 내용을 환기하고 학습 방향을 잡는 **비공식 참고·가이드용 자료**입니다. 공식 시험문제·정답기준·합격 판단자료를 대신하지 않으며, 내용의 정확성·완전성이나 실제 시험 출제를 보장하지 않습니다. 중요한 내용은 최신 교재·현행 법령·공식 자료를 우선 확인해야 합니다.

## 공개/비공개 경계

- 공개 GitHub: 무료100 프런트, `/extra/` 접근 셸, 문서
- 비공개 Apps Script: 보호 추가100 원문, 무료100 완주 레지스트리, 설문 제출 자동확인
- **보호 추가100(B001~B100)은 공개 저장소에 커밋하지 않습니다.**

## 데이터

개인별 정오답·점수·학습시간은 서버에 저장하지 않습니다. 이어보기 진행정보는 브라우저 내부에 저장하며, 서버에는 추가문제 개방을 위해 무료100 완주 여부·설문 제출 여부·동일 브라우저 확인용 무작위 값만 저장합니다.

## 운영

이번 자격시험 기간을 위한 일회성 학습도구입니다. 별도의 이용기간 만료는 두지 않습니다.
