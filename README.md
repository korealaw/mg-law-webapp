# MG 새마을금고법 톡톡 · 간부자격 학습

새마을금고법을 문제 → 핵심 → 이해 → 법령근거 순으로 학습하는 모바일 중심 웹앱입니다.

- 공개 프런트엔드: **v8.2**
- 백엔드 기준: Google Apps Script **v8.2 권장**
- 기준일: **2026-09-05**
- 공개 주소: https://korealaw.github.io/mg-law-webapp/
- 배포: GitHub Pages (`main` / root)

## 학습 흐름

1. 무료 학습 30문항
2. 미니 모의고사 20문항
3. 모의고사 제출 후 20문항 해설 순차 확인
4. 두 체험을 모두 마치면 연구 설문 안내
5. 설문에는 웹앱 인증코드가 자동 연결됨
6. 사용자가 실제 설문 제출 후 웹앱에서 `설문 제출 완료` 확인
7. 운영자가 설문 응답을 확인·승인
8. 승인 후 처음 상태확인/본학습을 실행한 기기·브라우저에 이용권 연결
9. 승인일부터 90일 동안 보호된 기본 100문항 학습
10. 기본 100문항은 전체 이어하기 또는 12개 파트/직접 범위, 기본·심화 모드로 학습

## v8.2 핵심 변경

- `설문 열기`와 `설문 제출 완료` 상태를 분리
- v8.1 계열의 모호한 설문 상태를 `legacy` 확인단계로 안전하게 이관
- 승인상태 확인 로직 단일화
- 만료/기기불일치와 승인대기를 명확히 분리
- 승인 처리시간을 특정하지 않도록 안내문 정비
- BASE100 이어하기 시 이미 별도 범위에서 완료한 문항을 기본적으로 건너뜀
- 12개 파트/직접 범위/기본·심화/학습완료 제외 기능 유지·보강
- 문제 로딩·승인 확인 시 진행 상태를 즉시 표시
- Open Graph/Twitter 대형 공유카드 메타데이터 복원
- 제한적인 브라우저 환경에서 localStorage 접근 실패로 앱 전체가 멈추지 않도록 부팅 경로 보강

## 공개 저장소 운영 원칙

이 저장소에는 공개 프런트엔드만 둡니다. 다음 항목은 **절대 공개 GitHub에 올리지 않습니다.**

- 보호 문제은행 `B001~B100` 원문
- Google Apps Script 전체 `Code.gs` 중 보호 문제은행 포함본
- 관리자 접근키
- 운영용 비밀값
- 설문 응답 원자료

보호 문제은행은 승인된 이용자에게만 Google Apps Script 백엔드가 필요한 구간을 전달합니다.

## 데이터 처리 요약

개인별 정오답·점수·학습시간은 서버에 저장하지 않습니다. 무료체험 이어하기와 BASE100 진도/범위 완료기록은 현재 브라우저의 로컬 저장소를 사용합니다. 승인 여부·승인일·만료일과 1기기 이용을 위한 무작위 기기 연결값은 백엔드에서 처리합니다.

## 운영 성격

무료·비상업적 연구 및 학습지원 도구입니다. 공식 유권해석, 업무지침 또는 법률자문을 대신하지 않습니다. 운영자는 본업과 연구를 병행하므로 기술문의·오류수정·개선요청의 즉시 처리나 처리시점을 보장하지 않습니다.
