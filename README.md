# mg-law-webapp

새마을금고법 학습 웹앱 공개 프런트엔드 저장소입니다.

- 공개 버전: v8.1a
- 기준일: 2026-09-03
- 배포: GitHub Pages (`main` / root)
- 공개 주소: https://korealaw.github.io/mg-law-webapp/
- 백엔드: Google Apps Script v8.1

## v8.1a 핵심 개선

- 40~50대 학습자 기준으로 문제·선택지·해설·탭 글자와 터치영역 확대
- 2단계 해설 기본 펼침, 오답 시 3단계 법령근거도 자동 펼침
- 해설 상단에 `놓치지 마세요 / 꼭 확인하세요` 안내를 추가해 해설 소비를 유도
- 카카오톡 등 URL 공유 시 MG 새마을금고 이미지·제목·설명이 함께 노출되도록 Open Graph 메타데이터 적용

## 운영 원칙

이 저장소에는 공개 프런트엔드만 둡니다. 보호 문제은행(BASE100), 관리자 접근키, 운영용 비밀값 및 관리자용 백엔드 소스는 공개 저장소에 포함하지 않습니다.

`main` 브랜치를 공개 운영 기준본으로 사용합니다.
