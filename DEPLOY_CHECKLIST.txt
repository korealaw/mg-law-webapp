7. 실제 제출 후 앱으로 돌아와 '설문 제출 완료' 클릭
8. 홈에서 '승인 확인하고 100문항 열기'가 표시되는지 확인
9. 관리자 승인 전에는 PENDING/REVIEW 안내가 맞는지 확인
10. 승인 후 처음 확인하는 기기·브라우저에 이용권이 연결되는지 확인

E. 승인 후 BASE100
1. '이어서 학습하기'를 누르면 즉시 '문제 불러오는 중…' 표시
2. 1~10 등 실제 문제 로딩 확인
3. 중간 종료 후 동일 브라우저 재접속 → 진도 복원
4. '범위를 선택해서 학습하기' → 12개 파트 표시
5. 직접 범위 입력 정상
6. 기본 학습: 정답 시 3단계 근거는 필요할 때 펼침
7. 심화 학습: 3단계 법령근거 자동 펼침
8. '이미 학습한 문항 제외' 동작 확인
9. 예: 연속 23/100 + 50~60 별도학습 후 일반 이어하기 → 24부터 시작하고 50~60은 건너뜀
10. EXTRA=0이면 추가문항 시작버튼이 나타나지 않는지 확인

F. 백엔드 v8.2 적용 후 확인
1. 기존 Apps Script 배포 URL을 유지한 채 새 버전으로 업데이트
2. /exec?action=health → version 8.2
3. questionBank.releaseReady = true
4. baseLoaded=100, baseUnique=true, baseOrderOk=true
5. 관리자 화면 자가점검 전체 PASS
6. 실제 승인 테스트 이용자에서 manifest/questions 정상
7. 다른 기기에서 DEVICE_MISMATCH 확인
